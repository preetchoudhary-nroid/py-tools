# Security Tools UI Suite

A comprehensive graphical user interface that integrates all the cybersecurity tools from the D2.py project into a single, easy-to-use application.

## Features

The UI includes the following tools organized in tabs:

1. **Password Generator** - Generate secure passwords with customizable options
2. **Caesar Cipher** - Encrypt, decrypt, and brute force Caesar cipher text
3. **File Organizer** - Automatically organize files by extension
4. **Hash Cracker** - Crack MD5 and SHA1 hashes using dictionary attacks
5. **Port Scanner** - Scan ports on target IP addresses
6. **Regex Extractor** - Extract IPs, emails, and URLs from text files
7. **Log Analyzer** - Analyze server logs for suspicious activity
8. **Subdomain Scanner** - Discover subdomains for a target domain
9. **Uptime Checker** - Monitor website availability and response
10. **Network Info Scanner** - Gather DNS and HTTP header information
11. **Directory Bruter** - Discover hidden directories on web servers
12. **Vulnerability Scanner** - Scan for known service vulnerabilities

## Installation

1. Make sure you have Python 3.x installed
2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the application:
```bash
python main.py
```

Navigate through the different tool tabs using the notebook interface at the top of the window. Each tool has its own dedicated interface with input fields and result displays.

## Requirements

- Python 3.x
- requests library
- tkinter (usually included with Python)
